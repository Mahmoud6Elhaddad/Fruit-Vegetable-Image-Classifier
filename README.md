# 🥭🍅 Fruit & Vegetable Image Classifier

A simple **Image Classification Web App** built with **Streamlit** and **TensorFlow/Keras** that can predict whether an uploaded image is a fruit or a vegetable, and identify its category.

## 📌 Features
- Upload an image (`.jpg`, `.jpeg`, `.png`)
- Model predicts the class (e.g., apple, tomato, carrot, etc.)
- Displays prediction with confidence score
- Easy-to-use web interface with **Streamlit**

## 🛠️ Tech Stack
- Python
- TensorFlow / Keras
- NumPy
- Streamlit

## 🚀 How to Run Locally
1. Clone this repository:
   ```bash
   git clone https://github.com/Mahmoud6Elhaddad/Fruit-Vegetable-Image-Classifier.git
   cd Fruit-Vegetable-Image-Classifier
2. Install dependencies:
   ```bash
   pip install -r requirements.txt
4. Run the Streamlit app:
   ```bash
   streamlit run app.py
5. 📦 Dataset
   The dataset used for training is available on Google Drive:
